# 📊 POSPAY COBIT 5 E-Evaluation System

**POSPAY COBIT 5 E-Evaluation System** is a web-based evaluation tool developed using the **COBIT 5** framework to assess the IT governance and **Capability Level** of PT. Pos Indonesia's (Persero) **POSPAY** application.

This system streamlines questionnaire data collection from respondents, automatically calculates capability metrics, and presents visual findings along with actionable recommendations for key stakeholders.

---

## 🌟 Key Features

- **Guest Questionnaire Access (No Login Required):** Enables respondents to fill out demographic data and answer evaluation items using a **Likert Scale (0 - 5)** seamlessly.
- **Automated COBIT 5 Calculation:** Instant calculation of capability levels (APO, DSS, and MEA domains) processed automatically by the application algorithm.
- **Comprehensive Admin Panel:** Allows admins to manage evaluation items, track respondents, view individual score breakdowns, and monitor calculations.
- **Stakeholder Dashboard:** Dedicated view for PT. Pos Indonesia stakeholders to monitor evaluation results and strategic recommendations.
- **Actionable Recommendations:** Generates targeted managerial recommendations based on COBIT 5 domain findings.
- **PDF Report Generation:** Enables stakeholders and admins to export evaluation results and capability reports directly into PDF format.

---

## 👥 User Roles & Access

| Role | Access & Responsibilities |
| :--- | :--- |
| **Respondent** | Fills out background information and completes evaluation questionnaires (Likert 0-5) without login. |
| **Admin** | Manages questionnaires, monitors respondent data, reviews score breakdowns, and views system calculations. |
| **Stakeholder** | Views COBIT 5 calculation dashboards, accesses system recommendations, and exports PDF reports. |

---

## 🛠️ Tech Stack

- **Backend & Frontend:** PHP, HTML, CSS, JavaScript
- **Database:** MySQL
- **PDF Generation:** FPDF / Dompdf
- **Development Tools:** VS Code, phpMyAdmin
